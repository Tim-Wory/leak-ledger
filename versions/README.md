# 历史版本

这些是 v4 之前的本地快照，保留用于回看演进过程。**不建议直接使用**：
它们缺少 v4 的交互、无障碍与健壮性修复（例如 v2 存在初始化顺序缺陷、
v3 存在读取存档未消毒的问题），详见根目录 [CHANGELOG](../CHANGELOG.md)。

| 文件 | 说明 |
| --- | --- |
| `v1.html` | 固定开支折算为每日流失，最早的完整版本 |
| `v2.html` | 增加日常流水与月度汇总（已知：初始化顺序缺陷） |
| `v3.html` | 对账单式视觉与图表（已知：存档消毒缺失） |
| `tests/` | 上述版本对应的 jsdom 回归脚本 |

当前版本请使用仓库根目录的 [`index.html`](../index.html)。
