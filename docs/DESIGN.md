# 漏钱账本 v4 · 设计说明

单文件、离线、localStorage 的「个人漏损测量仪」。这一版的目标不是加功能,而是把
**信息密度、材质对比、动效编排与交互手感**同时做到可参赛的水准。

---

## 1. 设计概念

**一台仪器 + 一本账。**

- 上方是**墨面仪器带**(Ink instrument):读数、量表、24 小时进程、支出流跑马。
  它是"测量"的部分,冷、准、克制。
- 下方是**纸面账本**(Paper ledger):收据式清单、快记条、月度汇总、曲线、今日签。
  它是"记录"的部分,暖一档、留白多。

两种材质在同一页里并存,靠一条实线硬切,不做渐变过渡 —— 对比本身就是叙事:
**上面告诉你钱怎么漏,下面让你把它记下来。**

## 3. 核心组件

- **机械滚轮数字(odometer)**:每位数字是一列 0–9,变化时滚动到位;`aria-hidden` +
  容器 `aria-label` + `data-value`,读屏只读最终值,不会念出 0-9 全表。
- **指针量表**:240° 弧,13 根刻度,红弧表示"已达成"比例,指针用 CSS `rotate` 缓动;
  刻度上限按 `niceMax` 自动取整(20/50/100/200/…)。
- **24 小时进程条**:红填充随当天时间推进,游标每分钟更新;「今日已过 / 已流走」并列,
  把"时间"与"钱"绑在同一个坐标上。
- **固定支出跑马**:每笔按期扣款一根刻度线 + 日成本;两端羽化,悬停暂停。
- **收据行**:序号 + 名称 + 虚线引导线 + 分类点 + 扣费倒计时 + 日均;悬停浮出操作,
  触屏常驻。
- **月度**:大号总额 + 固定/流水双口径分条 + 环图 + 去向 TOP5 + 月底预计;
  背景有 4% 的幽灵月份数字。
- **今日签**:四芒星盘 + 星座 + 综合分 + 四项细分 + 幸运色/数字/方位 + 宜忌 + 近期解析,
  使用确定性哈希,同一天刷新不变。

## 4. 动效与降级

滚轮滚动、量表指针、环图/分条填充、柱状逐根生长、累计线按真实路径长度自绘、
24h 填充过渡、页面进入位移、粘性迷你条滑入、跑马循环、星盘缓慢旋转、指示点呼吸。

- 全部只动 `transform` / `opacity` / `stroke-dashoffset`;
- `prefers-reduced-motion: reduce` 时全部关闭;
- 无 `requestAnimationFrame` 环境退化为 `setTimeout`;
- 无 `IntersectionObserver` 时不做滚动显现,内容照常可见。

## 5. 交互与可访问性

- 键盘:`N` 聚焦金额、`Enter` 保存、`⌘/Ctrl+Z` 撤回、`Esc` 关闭、`?` 快捷键表;
- 弹窗:焦点进入、`Tab` 循环陷阱、关闭后焦点归还触发元素;
- `aria-live` 播报总额变化;表单错误 `role="alert"` 且在对应字段下方;
- 触控目标 ≥ 24px,表单输入 16px 字号避免 iOS 缩放;
- 对比度:正文/标签在纸面与墨面上均按 AA 校正,小字灰已加深一档。

## 6. 数据可靠性

- 存储键沿用 `leak-ledger-v1`,v2/v3 的账本与备份可直接延续;
- **唯一消毒闸门** `coerceItem / coerceFlow`:load 与 import 共用,严格数字解析、
  未知枚举回退、日期校验、重复 ID 去重、缺 ID 时按内容哈希补齐;
- 撤销栈(最多 10 步):新增/删除/清空/流水均可撤回;
- 导出/导入 JSON 合并去重,不覆盖手头账本。

## 7. 验证

- jsdom 功能回归 **64 项全通过**:冷启动、示例、快记、撤销、CRUD、持久化、
  导出导入、脏存档、无 rAF、运势、键盘与弹窗;
- 无头 Chrome(Chrome for Testing)在 **1440 / 1024 / 768 / 390** 四个宽度截图核对;
- 页面在 `file://` 下直接打开无报错,断网可用。

## 8. 已知取舍

- 未做深色模式:墨面/纸面已是双材质,再接一套主题会打散一致性;
- 累计曲线延伸至月末,表示"若不再新增支出"的假设,并非真实数据;
- 今日签为娱乐性质,页面内已明确声明,不参与任何账目计算;
- 示例数据用于展示图表形态,首次使用建议点「示例数据」再「清空全部」。
